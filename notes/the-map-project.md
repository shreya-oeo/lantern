# the map project

Idea: a map where every pin is a place someone remembered rather than a place
they went. You can only add a pin by describing it from memory. No addresses.

Started it in a weekend. Got as far as drawing the pins. The pins were good.

Then I decided the data model was wrong and rewrote it three times, which is the
part where I always kill these things. I am very good at the part before the
schema.

Maybe the reason I stopped is that if the pins are memory then the map is mostly
wrong, and a map that is mostly wrong is honest but nobody wants to use it.

Still think about the pins.
